# Recorded sound overrides

Every sound in the game is synthesized by `scripts/sfx.gd`. To use a recording
instead, put `<id>.wav` or `<id>.ogg` here, named after the sound's id, and it
replaces the synthesized one. For example `pistol.wav` replaces Eco's shot.

Pistol ids: `pistol`, `pistol_last`, `dry_click`, `reload_out`, `reload_in`,
`boot`, `twirl`, `flourish`, `whack`, `lock_err`, `spark`.

Knife ids: `knife_draw`, `knife_swish`, `knife_hit`, `knife_spin`, `knife_catch`.

Only add sounds you are allowed to ship (CC0 is simplest) and note the source
and licence of each one below.
