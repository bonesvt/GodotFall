# Fonts

The HUD's type (`scripts/ui/hud_style.gd`), from Google Fonts. Both are under
the SIL Open Font License 1.1 (the `*-OFL.txt` next to them), which allows
bundling them with the game.

| File | Font | Used for |
| ---- | ---- | -------- |
| `Saira.ttf`, `Saira-Italic.ttf` | [Saira](https://github.com/Omnibus-Type/Saira), variable weight and width | words: cards, prompts, toasts, the radio, Eco's whispers (italic), dialogue |
| `Rajdhani-SemiBold.ttf`, `Rajdhani-Bold.ttf` | [Rajdhani](https://github.com/itfoundry/rajdhani) by the Indian Type Foundry | numbers: health, armour, rounds, grunts left, the run status |
